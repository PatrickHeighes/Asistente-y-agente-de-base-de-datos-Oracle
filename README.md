# Asistente-y-agente-de-base-de-datos-Oracle
Agente inteligente de texto a SQL modular para Oracle Database, desarrollado en Python con soporte de doble modo (Ask/Agent), análisis de impacto y control de confirmación interactiva (Human-in-the-Loop)

Creacion de entorno .venv
python -m venv venv

Activacion de entorno .venv
PowerShell
.\venv\Scripts\Activate.ps1
CMD
venv\Scripts\activate.bat

Instalar requerimientos
pip install -r requirements.txt

Correr el proyecto
python main.py
